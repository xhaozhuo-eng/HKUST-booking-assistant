# HKUST 预订助手

一个运行在用户本机 Chrome / Edge 中的开源浏览器扩展，用于配置 HKUST Sports Facility Booking System（FBS）的设施预订规则。它使用用户本人在浏览器中完成的登录会话，不需要把密码交给扩展或远程服务器。

## 使用方法

1. 下载本项目，在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 开启“开发人员模式”，选择“加载已解压的扩展程序”，选中本文件夹（其中应直接包含 `manifest.json`）。
3. 打开扩展设置，点击打开 HKUST 登录页面，由本人完成登录及可能出现的 MFA。
4. 同步官网项目，选择设施分类、位置和具体场地。设置目标日期规则、目标时段、候补时段、优先级和开放时间。
5. 先运行 Dry-run，核对扩展选择的设施、日期和时段。Dry-run 不会点击最终预订确认按钮。
6. 只有在确认符合 HKUST 规则并理解风险后，才选择自动模式，勾选本人授权并启用任务。
7. 运行时保持浏览器打开、电脑唤醒并联网。会话失效、验证码/MFA、未知页面或结果无法确认时，扩展会停止并要求人工处理。

默认时区为 `Asia/Hong_Kong`，开放时间为每天 08:00，默认目标日期为执行日期后第 7 个自然日。如果官网尚未显示时段控件，设置页会提供 08:00 至 21:00 的预设小时段供提前配置；每个时段都会在任务执行时与官网实时核对。用户可在设置中更改日期和时间规则。浏览器定时器可能延迟，睡眠或关闭的电脑无法执行任务。

## 适用网站与范围

- 目标网站：HKUST Sports Facility Booking System，新版学生、教职员及校友入口：`https://fbs.hkust.edu.hk/facilities`。
- 记录页：`https://fbs.hkust.edu.hk/bookings`。
- 适配器按运行时官网页面读取项目、场地、位置、日期和时段，不依赖固定坐标或每次刷新变化的 DOM ID。
- 目前已对真实新版网站的羽毛球代表流程进行 dry-run 检查，包括同名场地的位置区分、日期、时段和最终确认弹窗；未在真实网站提交预订。
- 自动提交和记录确认在隔离的模拟页面中测试。其他设施的附加规则、真实成功/失败弹窗及非空预订记录格式尚未逐项实测。
- 旧版家庭成员 / Sports Facilities User Card 入口（`w5.ab.ust.hk/fbs_user/`）目前不在适配范围内。

## 隐私与安全

- 扩展不读取或保存密码，不导出 Cookie；登录由用户在官方页面完成。
- 规则、运行历史及幂等记录存放在当前浏览器的扩展本地存储中。
- 不要分享浏览器配置目录、扩展存储、日志、截图或调试输出；这些内容可能包含账户或预订信息。
- 不要把真实账户数据、浏览器配置、`data/` 目录或私人构建产物提交到公开仓库。
- 不绕过 CAS、MFA、验证码、访问控制或网站风控。适配不确定时停止操作。

# Security

Do not report vulnerabilities by posting account data, cookies, browser profiles, tokens, screenshots, or booking records in a public issue.

Before sharing a bug report, remove personal information and include only the minimum sanitized reproduction needed. Never upload your browser profile or extension local storage. Do not test against another person's account.

The project maintainers do not operate a remote service and cannot reset or revoke an HKUST session. If you suspect a session was exposed, sign out of the official site and follow HKUST account security guidance.
